# 1. 选择轻量Alpine版Nginx作为基础镜像，锁定明确版本避免latest标签漂移,Dockerfile的起始必选指令
FROM nginx:1.25-alpine

# 2. 声明镜像维护者信息，替代已废弃的MAINTAINER指令
LABEL maintainer="your-name <your-name@example.com>"

# 3. 设置容器的工作目录，避免后续路径切换反复，默认进入该目录
WORKDIR /usr/share/nginx/html

# 4. 复制本地自定义的index.html到Nginx默认静态资源目录
COPY index.html .

# 5. 复制自定义Nginx配置文件，替换默认配置实现生产级优化
COPY nginx.conf /etc/nginx/nginx.conf

# 6. 声明容器内Nginx服务监听的80端口，作为元信息供编排工具参考
EXPOSE 80/tcp

# 7. 创建非特权用户，提升容器运行安全性
RUN addgroup -S nginx-group && adduser -S nginx-user -G nginx-group \
    # 清理Alpine系统包管理器缓存，减小镜像体积
    && rm -rf /var/cache/apk/* \
    # 修改静态资源目录和Nginx运行目录的权限，让非root用户可正常访问
    && chown -R nginx-user:nginx-group /usr/share/nginx/html /var/cache/nginx /var/run

# 8. 切换为非root用户运行容器，避免以最高权限启动服务
USER nginx-user

# 9. 指定Nginx以前台模式运行，容器默认启动命令，只能写一条,保证容器进程常驻不退出
CMD ["nginx", "-g", "daemon off;"]

这些是Docker入门阶段的核心基础指令，是理解镜像构建逻辑、完成基础实操的必备内容：
✅ FROM nginx:1.25-alpine：Dockerfile的起始必选指令，掌握它才能理解基础镜像的作用，避免使用latest标签带来的版本漂移问题。
✅ WORKDIR /usr/share/nginx/html：学习阶段必须掌握的路径管理指令，能避免反复写绝对路径的冗余操作，理解工作目录的自动创建规则。
✅ COPY index.html .：最常用的文件拷贝指令，是自定义镜像内容的核心操作，能直观理解镜像分层的文件写入逻辑。
✅ EXPOSE 80/tcp：掌握端口声明的元数据作用，区分“声明端口”和“实际端口映射”的差异，避免新手误以为EXPOSE会自动开放端口。
✅ CMD ["nginx", "-g", "daemon off;"]：理解容器启动默认命令的作用，掌握前台运行进程的配置逻辑，避免容器启动后立刻异常退出。

这些是保障镜像安全性、稳定性、轻量化的硬性要求，是生产上线前必须补充的加固配置：
✅ LABEL maintainer="xxx"：为镜像添加元数据标签，替代已废弃的MAINTAINER指令，方便团队协作时快速追溯镜像维护者信息。
✅ COPY nginx.conf /etc/nginx/nginx.conf：替换默认Nginx配置，实现生产级的连接数优化、日志配置、安全规则自定义，避免使用默认配置带来的性能和安全隐患。
✅ RUN 合并操作：将创建非特权用户、清理系统缓存、修改目录权限的操作合并执行，既减少镜像层数压缩镜像体积，又避免以root用户运行容器，大幅降低容器逃逸的安全风险。
✅ USER nginx-user：切换为普通非特权用户启动服务，是生产环境容器安全的核心规范，完全杜绝root权限带来的安全漏洞。
